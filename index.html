About Me

I've been interested in writing code for as long as I can remember. I got my first real introduction to it when an uncle of mine taught me HTML and CSS — and I was hooked from the start. There's something I still love about watching a design go from a blank page to something real and working in the browser; that moment is what's kept me building.


To sharpen those skills, I enrolled at SQI, where I strengthened my HTML and CSS and learned Bootstrap. SQI is also where I'm now getting introduced to cybersecurity — something I've actually been curious about for a while. If I'm honest, I used to want to be a hacker. These days, "ethical hacker" sounds a lot better — and that's the direction I'm leaning into.
